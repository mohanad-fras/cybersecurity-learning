## Overview

Bandit is a beginner-friendly Linux-based wargame from OverTheWire. I used it to practice working with the Linux terminal and basic file operations.

## Skills Practiced

- Connecting to a remote Linux machine using SSH.
- Listing files and directories.
- Reading files from the terminal.

- Searching through files and directories.
- Using basic Linux commands to locate information.
