# Linux — Day 01

## Goal

Start building practical Linux command-line skills for cybersecurity.

## Commands Practiced

### Navigation

```bash
pwd
ls
cd
```

- `pwd` shows the current directory.
- `ls` lists files and directories.
- `cd` changes the current directory.

### Files and Directories

```bash
mkdir test
cd test
touch notes.txt
ls
```

- `mkdir` creates a directory.
- `touch` creates an empty file.

### Reading Files

```bash
cat notes.txt
```

`cat` displays the contents of a file.

## What I Learned

- How to create directories and files.
- How to inspect the current directory.
- How basic Linux commands are used from the command line.
