# Module 03 - Wireless and Mobile Networks

## Topics Covered
- Wireless Networks
- Wi-Fi (IEEE 802.11)
- Bluetooth
- NFC (Near Field Communication)
- Cellular Networks (3G, 4G, 5G)
- Mobile Device Connectivity
- Wireless Security (WPA2 / WPA3)

## Key Concepts
- Understanding different wireless network technologies.
- Differences between Wi-Fi, Bluetooth, NFC, and cellular networks.
- Configuring mobile devices to connect to wireless networks.
- Understanding SSID and wireless authentication.
- Basic wireless security practices.

## Skills Gained
- Identify common wireless technologies.
- Configure a mobile device to connect to a Wi-Fi network.
- Distinguish between different wireless communication methods.
- Understand the basics of wireless network security.
